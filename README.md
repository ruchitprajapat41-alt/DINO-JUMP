## Features

- **full screen - phone + PC** - `100dvvh` for phone, `100vw / 100vh` for PC
- **Responsive Canvas** - `devicePixelRatio` - No blur on phone, sharp  on PC
- **Score Bar Fix** - SCORE never cuts - `SCOR` bug fixed
- **Attrative Background** - Real Mountain Photo + Moving Clouds + Sun + Birds
- **5 Obstacles** - From `database.json`
- **High Score Saved** - Using `localStorage`

## How To Play

### On PC

| key | ACtion |
|-----|--------|
| `SPACE` / `⬆️` / `W` | Jump |
| `⬇️` / `S` | Duck |
| `A` | Move left |

### On Phone 

| Action | How |
|--------|-----|
| Jump | Tap Anywhere on screen |
| Start | Tap START button |
| Play Again | Tap PLAY AGAIN Button |
